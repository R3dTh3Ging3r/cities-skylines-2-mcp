## Decisions that must remain gated

O3 verified completion requires adapter-specific effect/readback and cleanup predicates, late-effect reconciliation and honest unknown outcomes. The current registry must not accept an event named Finish as a verified receipt. O5 additionally needs every writer classified and admitted, an actual visible player-control hook, and no new native dispatch after takeover acknowledgment; direct zoning/setters, deferred work, camera, simulation and saves must not bypass it. These are source implementation and native validation requirements, not features supplied by tracing.

O4 needs a newly requested save's task/event/destination package attribution, durable readback and preview ownership. Passive task capture supplies only managed terminal observations, with explicit bounded retention and possible loss; it is not an operation receipt. Observation timestamps can follow actual task completion and appear before or after the legacy reply. The existing named checkpoint's readability does not establish the missing facts. O6/O7 mutation supervision depends on O3/O5 and verified pause/termination. C2 previews and C3/C4/C5 preservation, complete facility/connector semantics, cargo/air operations and unit/calendar/panel parity retain their separate action-specific evidence requirements.

The supported construction-phase and save-task capture is sufficient for this evidence increment. Further completion, takeover or durable-save implementation must use the missing native evidence rather than add unused instrumentation or fabricate predicates. Gather these checks together when a native session is separately authorized; this document does not request a routine small test or enable guarded writers.
