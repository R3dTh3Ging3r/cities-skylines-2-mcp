# Cities Skylines II Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. Native execution in this session is recommended because installation and live game checks are sequential.

**Goal:** Connect Codex to the running Steam game through a personal fork of the existing bridge and verify a small construction exercise.

**Architecture:** Retain the upstream C# game mod and Node MCP server. Codex calls the local Node process, which forwards requests to the loopback game bridge. Add compatibility fixes only for demonstrated failures.

**Tech Stack:** Windows, PowerShell, Git/GitHub, C# targeting net472, .NET SDK, Node, TypeScript, MCP.

**Spec:** [Approved adaptation design](../specs/2026-10-08-cs2-bridge-design.md).

5. Geometrically adjacent road that is not connected: inspect the road graph and resulting entities, not only a screenshot. Checked in Task 3.
